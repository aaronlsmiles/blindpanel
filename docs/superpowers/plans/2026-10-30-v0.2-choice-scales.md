# blindpanel v0.2: choice scales Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A study can declare a scale of `kind: choice` (2–12 unordered options, answered 1…n) beside the existing five-point ordinal scale, and everything downstream (compile, lock, payload check, page, flags, tally, export, report) handles it, with every v0.1 `study.yaml` compiling, locking and running exactly as before.

**Architecture:** `scales.<id>.kind` is `ordinal` (the default, exactly 5 labels, unchanged) or `choice` (2–12 labels). The compiled `Scale` gains `kind` and `max`; every place that hard-coded "1 to 5" asks the scale instead, through four small helpers in a new `src/core/scale.ts`. The instrument hash serialises an ordinal scale exactly as v0.1 did (no `kind` key), so existing locks still verify. Nominal Krippendorff's α sits beside the ordinal one and shares its coincidence matrix.

**Tech Stack:** TypeScript 7.0.2 (ESM, `strict`, `noUnusedLocals`), zod 4, Vitest 5 + jsdom, PGlite (the SQL tests), Playwright + axe (e2e). No new runtime dependencies.

```ts
import type { Scale } from "./types.js";

/** A `study.json` built before 0.2 has no `kind`: it is ordinal. */
export const isChoice = (s: Pick<Scale, "kind"> | undefined): boolean => s?.kind === "choice";

/** The highest answer a scale takes. A `study.json` built before 0.2 always had `max: 5`. */
export const scaleMax = (s: Pick<Scale, "max"> | undefined): number => s?.max ?? 5;

/** The number key → the option it selects: 1–9 are themselves, 0 is the tenth. */
export const keyValue = (key: string): number | null => (/^[0-9]$/.test(key) ? (key === "0" ? 10 : Number(key)) : null);

/** The key hint shown on option `v`: 1–9, then 0 for the tenth. The 11th and 12th have no key. */
export const valueKey = (v: number): string | null => (v >= 1 && v <= 9 ? String(v) : v === 10 ? "0" : null);
```

```ts
import { isChoice } from "../core/scale.js";
import type { Study, Submission } from "../core/types.js";

export type Flag = "straightline" | "too_fast";

/** Flags mark a row for the tally to leave out. They never reject it: every submission is stored. */
export function flagsFor(study: Study, s: Submission): Flag[] {
  const flags: Flag[] = [];
  // Straightlining is one score repeated on a scale. Options of a choice question have no scale to
  // flatline on (a rater may truly pick the same option every time), so only ordinal questions count.
  const ordinal = new Set(study.questions.filter((q) => q.part === "clips" && !isChoice(study.scales[q.scale])).map((q) => q.id));
  const values = Object.values(s.answers.clips).flatMap((a) =>
    Object.entries(a).filter(([q]) => ordinal.has(q)).map(([, v]) => v),
  );
  if (s.order.clips.length >= 2 && new Set(values).size === 1) flags.push("straightline");
  if (s.delivery.duration_s < 0.5 * s.order.clips.length * study.parts.clips.clip_seconds) flags.push("too_fast");
  return flags;
}
```

```ts
/**
 * Nominal Krippendorff's alpha, for choice questions: any two different options disagree equally
 * (difference 0 if equal, 1 otherwise), so the order of the option numbers carries no meaning.
 * Same coincidence matrix as the ordinal alpha; only the difference function changes.
 * matrix: raters x items, values 1..12 or null. Null when nothing is pairable or nobody varies.

export function krippendorffNominal(matrix: Maybe[][]): number | null {
  return alphaFromCoincidence(coincidence(matrix), "nominal");

/** The coincidence matrix over the values present, in ascending order (a line-for-line port, see above). */
function coincidence(matrix: Maybe[][]): number[][] {
  const present = new Set<number>();
  for (const row of matrix) for (const v of row) if (finite(v)) present.add(Math.trunc(v));
  const values = [...present].sort((a, b) => a - b);
  const vi = new Map(values.map((v, k) => [v, k]));
  const V = values.length;
  const coin = Array.from({ length: V }, () => new Array<number>(V).fill(0));
  const nItems = Math.max(0, ...matrix.map((r) => r.length));
  for (let j = 0; j < nItems; j++) {
    const vals = matrix.map((r) => r[j]).filter(finite);
    const mu = vals.length;
    if (mu < 2) continue;
    const idx = vals.map((v) => vi.get(Math.trunc(v))!);
    for (let i = 0; i < idx.length; i++)
      for (let k = 0; k < idx.length; k++) if (i !== k) coin[idx[i]][idx[k]] += 1.0 / (mu - 1);
  }
  return coin;
}
```

```markdown
## 2026-10-30: choice scales (0.2)

An audit before any code found two places the "five labels" assumption lived that nobody had listed.

- **The tally dropped options silently.** `sql/schema.sql`'s `tally()` kept only `^[1-5]$` and built five counts, and the JS tally pre-filled `[0,0,0,0,0]`.
```
